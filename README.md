# JavaScript Module Pattern – Warenkorb Demo

Dieses Projekt zeigt das **Module Pattern** in Vanilla JavaScript anhand eines einfachen Beispiels: einem **Warenkorb-Modul**, das Produkte verwaltet.


##  Was ist das Module Pattern?

Das Module Pattern nutzt JavaScript Closures, um **private Zustände** zu verwalten, Nur explizit freigegebene Funktionen oder Werte sind von aussen zugänglich/ für Datenkapselung.
